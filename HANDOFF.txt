최초 Git 설치·clone 순서와 실행 안내는 README.txt를 읽으세요.
원본 컴퓨터의 절대 경로·서버 PID·브라우저 탭 ID는 역사 기록이며 새 컴퓨터에서 재사용하지 않습니다.
대화 자체를 이관한 것은 아닙니다. 새 Codex 대화에는 CONTINUE_PROMPT.txt 내용을 전달하세요.
이전 Mac의 실제 복원 검수 범위와 결과는 .transfer/VALIDATION.json, .transfer/READY.json을 확인하세요.
이 기록은 다른 컴퓨터·운영체제 검증이나 현재 Git 원격 상태의 증거가 아닙니다.

게임 실행에는 외부 npm 패키지나 Python이 필요하지 않습니다.

31종 적군의16방향×32샘플 보행,19개 접지 수정 리그·원본 클립,무드보드50장과 제작 기록을 포함합니다.
기존 source geometry/UV/texture와 역사 증거를 재생성하거나 대체하지 않았습니다.
주인공 기본 실제 속도128/회피400 및 기존 성장·장비 비율을 유지합니다.
남은 개선은 주인공 전용 옆걸음·독립 상체 조준, 최종보스 정밀 접지, 모바일 메모리·성능 검수입니다.
현재 이미지 디코드 추정은 정상상주526.91MiB/성공한 두 장면 전환758.29MiB이며 실측 RAM·VRAM·FPS가 아닙니다.
플레이 저장은 이전 브라우저 localStorage에 있습니다. 이 폴더와 Git으로 옮겨지지 않습니다.
automation-7은 재개하지 않습니다. 키·토큰·서명자료·브라우저 프로필을 Git에 추가하지 않습니다.

Git으로 관리할 때
프로젝트 전체 상대 경로를 유지해야 테스트·원본 렌더·모델 경로가 함께 복구됩니다.
이관본에 .gitattributes를 준비했습니다. PNG/GLB 등은 Git LFS 대상이며 모든 파일의 줄바꿈 변환을 꺼 byte 해시를 보존합니다.
Git LFS를 양쪽 컴퓨터에 설치하고 git lfs install을 마친 후 커밋해야 합니다.
Git LFS가 없는 상태로 대량 git add를 실행하지 마세요. 원격 저장소·용량 조건을 먼저 확인합니다.
이전 이관 검수 기록의 gitPush:false는 당시 상태입니다. 실제 원격·커밋·푸시 상태는 현재 Git에서 확인합니다.
유료 저장 공간·트래픽 결제를 수행하거나 사용자 승인을 추정하지 않습니다.
과거 nested .git과 Codex 인증 상태는 제외했습니다. 기존 컴퓨터의 저장소·커밋은 그대로 남아 있습니다.
압축본은 Git 없이도 옮길 수 있습니다. 압축을 푼 뒤 npm run verify로 모든 파일의 SHA-256을 확인하세요.
