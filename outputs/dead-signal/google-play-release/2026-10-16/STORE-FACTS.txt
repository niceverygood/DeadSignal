게임 코드와 이미지가 앱에 포함된다. 런타임 프로덕션 아트 로더는 앱 내부 localhost 경로를 사용한다. 이것은 Capacitor 가상 자산 핸들러이며 외부 게임 서버 연결 기능이 아니다.

Android 앱 백업은 allowBackup=false/fullBackupContent=false다. 평문 통신과 WebView 원격 디버깅을 껐다.

위 내용은 정적 코드와 현재 산출물 확인이다. 실제 기기 전투·멀티터치·음향·백그라운드 복구와 Google 심사 승인을 대신하지 않는다. 기존 BUILD-AND-SUBMISSION.txt 역시 네이티브 실제 UI 검증을 미완료로 기록한다.

3. IARC 질문에 사용할 실제 콘텐츠 사실

아래는 공개 정책과 실제 코드·관찰 자산을 연결한 답변 근거다. 현재 계정의 실제 IARC 문항을 읽은 결과가 아니므로 문항 문구를 그대로 인용한 목록이나 이미 제출된 답변으로 취급하지 않는다. 정확한 문항의 정의를 읽고 아래 사실에 맞춰 답한다.

폭력 유무: 있음. 총기 사격, 못총, 화염병, 폭발, 전기 공격으로 좀비와 보스를 처치하는 것이 반복되는 핵심 플레이다. 일시적/극히 드문 폭력으로 설명하지 않는다.
공격 대상: 인간처럼 생긴 좀비, 변이 괴물, 인간형 생존자. 생존자도 피격·사망한다. 단순히 ‘비인간 대상만 있는 순수 만화 폭력’이라고 축소하지 않는다. 실제 문항이 human-like와 non-human을 나누면 그 정의와 자산 외형을 확인한다.
그래픽 형태: 3/4 시점의 텍스처가 있는 3D 캐릭터와 어두운 도시 환경이다. 만화적/양식화된 부분이 있지만 총기·좀비 신체·피 표현이 있으므로 저연령용 추상 도형 전투라고 선언하지 않는다. 사진 같은 실사 영상이나 실제 폭력 촬영물은 없다.
피/혈흔: 있음. engine.js damageEnemy의 blood 파티클(#a64742), renderer.js의 혈흔과 blood 렌더링, 사체 렌더링을 확인했다. 좀비의 찢어진 옷과 상처 있는 외형도 보인다. ‘피 없음’ 답변은 현재 코드와 맞지 않는다.
사체: 있음. 처치 후 바닥에 쓰러진 몸을 그리고 일정 시간이 지나면 없앤다.
신체 절단/내장 노출/고문/성적 폭력: 코드에 별도의 절단·장기 노출·고문 연출은 확인하지 못했다. 그러나 이 검토에서 24보스와 모든 캐릭터 텍스처를 확대 검수한 것은 아니므로 상세한 gore 문항에 대한 최종 No를 이 문서만으로 보증하지 않는다. 실제 문항이 이를 물으면 해당 아트의 최종 확인을 수행한다.
공포/겁주는 내용: 좀비·괴물·어두운 폐도시·추격·경보가 있어 공포 테마 있음. 강한 공포감 여부와 빈도는 실제 문항 정의를 읽어 판단한다. 광고용 아이콘이 부드럽다는 이유로 게임의 공포 테마를 없다고 하지 않는다.
욕설/강한 언어: 검사한 게임 UI 문구·소스에서 욕설을 찾지 못했고 음성 대사는 없다. 효과음은 WebAudio로 만든 총격·폭발·경보 등이다. 사용자 채팅도 없다.
성적 콘텐츠: 성행위·성적 대사·성적 서비스·성기 노출은 확인되지 않는다. 일부 좀비의 상반신이나 찢어진 옷이 보이므로 문항이 비성적 노출까지 별도로 묻는다면 그 실제 이미지와 정의를 따른다.
도박/현금성 보상: 실제 돈을 거는 도박, 카지노, 베팅, 현금 환전, 현금성 상품 지급 없음. 무작위 로그라이크 개조 선택은 존재하지만 돈을 걸어 재산상 이익을 얻는 기능이 아니다.
유료 랜덤 아이템/확률형 구매: 없음. 테스트 상점도 현재 모바일 UI/액션에서는 사용할 수 없다.
술/담배/마약 소비: 음주·취한 상태·흡연·마약 사용을 구현한 내용은 확인되지 않는다. 화염병 형태의 병과 병원의 약품/수액은 존재하므로 ‘병 모양 소품도 전혀 없음’이라고 설명하지 않는다.
사용자 상호작용/UGC: 채팅, 사용자 게시물, 콘텐츠 업로드, 멀티플레이, 타인과 기록 공유 없음.
무제한 웹 접근/외부 브라우징: 앱 안의 범용 웹 검색·주소 입력·제한 없는 웹 콘텐츠 탐색 없음.
위치 공유/개인정보 요청: 없음.
광고: 현재 바이너리 없음.
인앱 구매: 현재 바이너리 없음.

Google은 질문에 정확하고 완전하게 답한 뒤 계산된 지역별 등급을 확인하도록 안내한다. 콘텐츠가 달라지면 재신고가 필요하다. 이 문서에서 12세/15세/16세 등급을 확정하거나 생성하지 않았다. 한국의 게임 등급은 일반 앱의 Google Play 연령 아이콘과 구분해야 한다. 공식 근거: https://support.google.com/googleplay/android-developer/answer/9859655?hl=en

아동 대상 여부는 연령등급과 별도 항목이다. 현행 초안은 childDirected=false이며 게임의 좀비·피·총격 테마와 맞지만, 최종 목표 연령 선택은 실제 콘텐츠와 출시 대상에 맞춰 Console에서 확인한다. ‘전체 이용가’나 Families 대상이라는 홍보를 먼저 붙이지 않는다.

4. Data safety에 사용할 목록

현재 Android 1.0.0의 게임 기능에 근거한 답변 후보: 필수 사용자 데이터 유형을 수집하거나 공유하는가 → 아니요. Google에서 기기 밖 전송을 수집으로 정의하며, 기기 안에서만 처리하는 데이터는 신고 대상에서 제외할 수 있다는 공식 설명과 연결된다. 광고/분석 SDK가 없는 현재 바이너리에만 적용한다. https://support.google.com/googleplay/android-developer/answer/10787469?hl=en

위치: 수집/공유 없음. 위치 권한이나 GPS/IP 기반 위치 분석 기능 없음.
개인정보: 이름·이메일·전화번호·주소·회원 ID 등을 게임에서 입력받거나 전송하지 않음.
금융정보: 결제정보·신용카드·구매내역 수집/공유 없음. 실제 결제 없음.
건강/피트니스: 없음.
메시지: 이메일/SMS/앱 채팅 수집/공유 없음. 게임 밖에서 사용자가 자발적으로 지원 이메일을 보내는 운영은 공개 정책에 별도로 설명해야 함.
사진/동영상: 사용자 미디어 수집/업로드 없음. 번들 게임 그림은 사용자 미디어 데이터가 아님.
오디오: 마이크 녹음/사용자 음성 수집 없음. 게임 효과음 출력만 함.
파일/문서: 사용자 문서 읽기·전송 없음. 앱 자체 저장은 로컬 게임 프로필.
캘린더: 없음.
연락처: 없음.
앱 활동: 플레이 기록·작전·설정이 기기에 남지만 개발자 서버나 SDK로 보내지 않음. 오프디바이스 수집/공유 없음.
웹 브라우징: 웹 탐색 기록 수집/공유 없음.
앱 정보/성능: 앱의 분석·오류 수집 SDK나 서버 전송 없음. OS/스토어 자체 진단 처리는 해당 플랫폼의 정책과 실제 Console 동작을 구분한다.
기기 또는 기타 ID: 광고 ID·Android ID·계정 ID를 수집/전송하지 않음. 로컬 runId는 게임 작전 중복 방지용이며 서버로 보내지 않음.

계정 생성 방식: 지원하지 않음. 단순 로컬 게임 프로필은 이름·이메일·비밀번호로 가입하는 사용자 계정 기능이 아니다.
앱 액세스: 로그인이나 테스트 계정 없이 전체 출시 기능에 접근 가능. 첫 미션→출격 준비→시작으로 검토 가능. 순차 미션 해금과 게임 내 진행은 존재한다.
데이터 삭제: Android 시스템 설정의 앱 데이터 삭제로 로컬 기록을 제거할 수 있다. 서버 계정·서버 데이터·계정 삭제 요청 URL 기능을 구현했다고 주장하지 않는다. 계정 생성 앱에 대한 삭제 정책은 현재 앱의 해당 기능 유무와 구분한다.
전송 중 암호화: 전송할 사용자 데이터가 없는 현재 앱에 적용할 외부 전송 구간이 없다. localhost 가상 HTTPS 자산 URL을 근거로 ‘외부 개인정보 전송은 전부 암호화’라고 추가 주장하지 않는다. Console이 보여주는 해당 없음/분기 선택지를 따라야 한다.
독립 보안 검증: 받았다고 신고할 근거 없음. Families 준수 배지, 독립 보안검증 배지 등을 임의 선택하지 않는다.

Data safety는 SDK를 포함한 실제 처리와 일치해야 한다. 향후 광고/IAP/분석/클라우드 기능을 같은 패키지의 배포 버전에 추가하면 현재의 수집 없음 신고와 공개 정책을 실제로 갱신해야 한다. 현행 BM 기획만 있다는 이유로 지금 광고 SDK가 있다고 신고하거나, 반대로 향후 SDK를 추가하고 지금의 무수집 신고를 그대로 쓰지 않는다.

5. 개인정보·고객지원 공개 초안의 실제 누락

현재 store/privacy-policy-draft.html은 제목과 본문에 ‘게시 전 초안’, 운영자·연락처 미확정이라고 적혀 있다. 로컬 HTML 경로는 공개 개인정보 URL이 아니다. in-app mobile-privacy.js에는 기기 저장·수집/광고/IAP 없음·기록 삭제 안내가 있어 앱 안의 설명은 준비되어 있다.

출시에 필요한 미확정 사항:
공개 지원 이메일: 실제 확인된 주소 없음. Google 등록에 이메일 연락처가 필요하고 입력하면 스토어에 공개된다. 회사 도메인을 추정해 주소를 만들거나 사용자 개인 휴대전화를 무단 기입하지 않는다. https://support.google.com/googleplay/android-developer/answer/9859152?hl=en
공개 개인정보 HTTPS URL: 아직 제공·공개 확인된 주소 없음. 로그인·지역 제한 없이 열리는 읽기 전용 HTML로 게시하고 그 실제 URL을 Console에 연결해야 한다. PDF나 로컬 파일로 대체하지 않는다.
게시 운영자: 게시 계정의 실제 개발자/법인 정보와 앱 식별을 맞춘다. 현재 앱 이름은 정책에 있지만 운영자는 ‘확정 전’이다. 사용자 회사 정보를 다른 게시 계정에 자동 대응시키지 않는다.
개인정보 문의 방법: 실제 지원 이메일 또는 문의 기능을 확정해 공개 정책에 적어야 한다. 현재 ‘스토어 연락처 참고’와 ‘게시 전에 확정’ 문구만 있는 초안을 완성된 운영 연락처로 취급하지 않는다.
지원 문의 보관·삭제: 초안에서 미정으로 남아 있다. 수신하는 지원 이메일의 실제 처리자·사용 목적·보관 기준·삭제 방법과 보안 접근 관리를 확인해야 한다. 임의의 ‘30일 보관’ 같은 운영 사실을 만들지 않는다.
공개 정책의 최종 날짜와 초안 표시: 실제 확정·게시 후 업데이트하고, 그 URL을 비로그인 환경에서 다시 열어 확인한다.

모든 앱은 무수집이어도 공개 정책이 필요하다. 정책에는 운영자/연락 방법, 데이터 처리, 보안, 보관·삭제를 적고 앱/개발자 식별을 맞춰야 한다. 공식 정책: https://support.google.com/googleplay/android-developer/answer/10144311?hl=en

6. 스토어 이미지와 검증 누락

기존 google-app-icon-512.png는 PNG RGB 512×512, google-feature-graphic-1024x500.jpg도 준비되어 있다. 원본과 그림을 변경하지 않았다.
기존 유일한 mobile-web-landscape-game.png는 RGB 1688×780으로 긴변/짧은변 비가 2.1641이다. Google 스크린샷 규격의 2:1 이내 조건을 넘고 최소 두 장도 채우지 못한다. 이것은 모바일 Chromium QA 증거이며 네이티브 실제 기기 검증 증거가 아니다.
제출용은 실제 배포 앱 경험을 보여주는 16:9 1920×1080 등의 새 캡처 두 장 이상을 준비하는 것이 적절하다. 게임 추천 노출용 권장 조건과 게시 필수 조건을 구분한다. 개인정보/장비 텍스트를 가짜 기능처럼 붙이거나 BM 미구현 상품 화면을 현재 게임 화면으로 제출하지 않는다.
공식 이미지 지침: https://support.google.com/googleplay/android-developer/answer/9866151?hl=en

7. root가 실제 출시에서 남겨야 할 구분

현재 unsigned AAB와 디버그 APK가 존재하는 상태와, 배포 서명·Play App Signing·Console 업로드·심사 제출·심사 통과·공개 배포는 서로 다르다. 이 검토는 어느 단계도 새로 완료하지 않았다.
패키지 ID는 출시 후 바꾸는 임시 표시명이 아니다. 실제 게시 계정·패키지 선택과 키가 확정되었는지 root가 확인한다. Google 공식 등록 가이드에서 패키지 이름은 고유하며 재사용/삭제에 제한이 있다고 안내한다. https://support.google.com/googleplay/android-developer/answer/9859152?hl=en
IARC 최종 질문과 결과, 목표 연령, 배포 국가, 광고 없음, 인앱 구매 없음, 앱 접근, Data safety, 공개 개인정보·지원 연락처를 현재 바이너리에 맞춰 채운다. 건강·금융·정부·뉴스 같은 별도 선언 화면이 나타나면 좀비 게임의 허구적 병원/약품/돈 단어를 실제 의료·금융 서비스라고 혼동하지 않는다.
사용자 웹 프로필·진행 중 작전과 모바일 동결 산출물은 이 보고를 위해 수정하지 않았다. 개인 연락처, 서명키, 계정 정보는 파일에 넣지 않았다.
