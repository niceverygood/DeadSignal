게시 전 초안. 운영자와 공개 문의 연락처를 확정하고, 접근 가능한 HTTPS 주소에 게시한 뒤 스토어에 연결해야 합니다. 현재 이 파일은 공개 정책 URL이 아닙니다.

데드 시그널 모바일 개인정보 처리방침

대상: 모바일 1.0.0 · 작성일: 2026년 10월 16일

1. 기기 내 저장

작전 진행, 처치 기록, 해금, 보강, 설정을 앱의 기기 내 저장 공간에 저장합니다. 로그인이나 이름·이메일 입력 없이 플레이할 수 있습니다.

2. 게임에서 수집·전송하는 정보

이 버전은 게임 기록을 개발자 서버로 전송하지 않습니다. 광고, 분석, 추적 SDK와 실제 결제 기능이 포함되어 있지 않으며, 게임 코드와 이미지는 앱에 포함됩니다. 운영체제와 스토어의 진단·백업 등 시스템 기능에는 해당 서비스의 정책이 적용됩니다.

3. 삭제·보관·이전

Android에서는 시스템 설정의 앱 데이터 삭제로 기록을 지울 수 있습니다. iOS에서는 앱 삭제로 기기 내 기록을 삭제할 수 있으며 앱 정리하기는 기록을 남길 수 있습니다. 웹 브라우저의 기록은 앱으로 자동 이전되지 않고, 개발자가 제공하는 클라우드 동기화는 없습니다.

4. 문의 시 처리

사용자가 이메일로 문의를 보내면 이메일 서비스와 수신자가 사용자가 직접 보낸 내용과 회신에 필요한 이메일 주소를 처리합니다. 공개 문의 이메일, 문의 보관 기간과 담당자 정보는 게시 전에 실제 운영 방식에 맞게 확정해야 합니다.

5. 변경

결제, 광고, 클라우드 저장 등 데이터 처리 방식이 바뀌는 기능을 추가하면 실제 처리에 맞춰 이 방침과 스토어의 개인정보 신고를 갱신합니다.

운영자·연락처 확정 전 초안. 자동 생성된 URL이나 검증되지 않은 연락처를 기입하지 않았습니다.
