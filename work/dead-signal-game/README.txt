DEAD SIGNAL — v0.29.0 적군 보행 개선

일반 적7종·중간보스12종·최종보스12종의 보행을 각각16방향×32프레임으로 새 렌더했다.
주인공의 v0.28 이동128·회피400 조정은 유지한다. 적의 게임 속도·AI·공격·충돌·저장 형식은 변경하지 않는다.
인간형19종은 원본 스킨 발바닥과 관절을 측정하고 다리 회전만 보정한 새 이동 클립을 쓴다.
원본 메시·UV·텍스처·스킨·바인드·기존 모든 동작은 보존했다. 상체나 루트를 위로 띄우지 않았다.
최종보스12종은 기존 체형별 다관절 원본을32위상으로 렌더하며 이동 주기는 체형 기반 근사다.
실제 이동 거리와 체형별 보폭으로 재생하고, 서로 다른 시작 위상과 완만한 방향 전환을 적용한다.
공격 경고·돌진·방패 방향은 정확한 실제 판정 방향을 즉시 표시한다.
이동 중 피격과 넉백이 발걸음을 정지 전신 자세로 덮지 않으며 넉백 중 다리 주기는 잠근다.
정지는 보정된 이동 원본의 첫 자세를 사용한다. 기존 전투 리그는 공격·사망 등에서 계속 사용한다.

원본 보존 및 한계
공개32 보행 위상의 발바닥은 바닥 위다. 위상 사이 정밀128샘플에서는 최대0.094월드단위 미세관통이 남는다.
다리 도달 한계 때문에 일부 발의 XZ는 최대2.277월드단위 변하며, 재측정 보폭으로 보상했다.
이동 전용 교정이고, 기존 전투 클립의 모든 해부학적 자세를 최종 승인한 것은 아니다.
주인공 전용 옆걸음·손가락 재장전, 최종보스 정밀 접지 IK는 별도 제작 범위다.
검수 화면 enemy-motion-review.html은 실제Game/Renderer를 쓰며 저장소에 접근하지 않는다.

DEAD SIGNAL — v0.28.0 주인공 이동 개선

기본 실제 속도214→128(40.2% 감속), 회피 속도675→400(40.7% 감속).
기존 저장 speed=214 및 장비·성장 보너스 비율은 그대로 읽고 실제 변위에 새 비율을 적용한다.
입력을 놓으면 그 시뮬레이션 단계에서 즉시 정지한다. 관성 저장 필드는 추가하지 않았다.
원본 GLB 발 접지 궤적으로 측정한 걷기39.37121·달리기84.94224 world/cycle에 실제 이동 거리를 맞춘다.
기본128 이동은32샘플 조깅을 사용하고 느린 아날로그 입력은 걷는다. 후진 시 발걸음을 역재생한다.
이동 중 사격·피격이 전신 자세로 다리 동작을 덮지 않는다. 정지 사격·피격·사망은 기존 실제 리그를 유지한다.
현재 전신 원본에는 옆걸음 전용 동작이 없으므로 옆 이동의 완전한 발 잠금은 추가 스트레이프 제작 범위다.

DEAD SIGNAL — v0.27.0 로컬 웹 플레이 버전

24종 보스(중간 12·최종 12), 일반 적 7종, 생존자 1종의 원본 메시·UV·텍스처를 보존한 32개 리그 본체를 사용합니다.
생존자의 산탄총·못총 장착 차이를 포함하면 새 동작 아틀라스는 33종입니다.

각 새 동작 아틀라스는 16방향 × 32샘플 = 512프레임이며,
대기 4·걷기 8·스킬 준비 6·공격 6·피격 2·사망 6샘플을 분리해서 선택합니다.
기존 생존자 고해상도 걷기·달리기는 각 동작 32샘플을 그대로 유지합니다.
실제 보스 스킬·근접 공격·피격·사망에 맞춰 원본 캐릭터의 동작을 표시합니다.
생존자의 전용 재장전 손·탄창 동작은 추가 제작이 필요하며, 기존 재장전 표시는 유지합니다.

투명한 여백만 무손실로 정리하여 원본 해상도와 보이는 RGBA 픽셀을 보존합니다.
보스 도감의 작은 초상·HD 초상은 승인된 기존 파일을 그대로 사용합니다.
기존 플레이 기록을 보존하며, 검수 장면은 계정·저장소에 접근하지 않습니다.
